# 드림 매일큐티

매일 Quiet Time을 기록하고, 순(그룹) 참여 현황과 월간 랭킹을 확인하는 웹 앱 **「드림 매일큐티」 Phase 1 프론트엔드 프로토타입**입니다.

> 실제 카카오 로그인 / Supabase는 포함되어 있지 않습니다. 테스트 로그인만 제공합니다.

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- Lucide React
- Mock 데이터 (`src/lib/mock-data`) — 약 300명 / 30순 / 최근 3개월 QT

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

프로덕션 빌드:

```bash
npm run build
npm start
```

## 테스트 로그인

1. 앱 실행 후 `/login` 으로 이동합니다.
2. **「테스트로 시작하기」** 버튼을 누릅니다. (실제 카카오 로그인이 아님을 화면에 명시)
3. 테스트 계정 `테스트유저` (사랑순, 관리자)로 오늘의 QT에 입장합니다.

로그아웃은 마이페이지(`/me`)에서 할 수 있습니다. 세션은 브라우저 `localStorage`에만 저장됩니다.

## UX 규칙 (요약)

- **순 배정:** 관리자가 일괄 배정합니다. 사용자가 스스로 순에 가입하지 않습니다.
- **QT 완료:** 단순 체크가 없습니다. 오늘 나의 묵상 / 마음에 남는 구절 / 결단과 순종 / 묵상 후 나의 기도제목을 작성하고, **전체 합쳐 공백 제외 10자 이상**이어야 저장·완료됩니다. 기록 삭제로 완료 취소·수정 가능합니다.
- **본문 범위:** 날짜별 QT 본문(mock)을 홈·오늘의 QT·기록에서 표시합니다.
- 타 순원의 기록 텍스트는 노출하지 않습니다 (완료/일수만).

## 주요 화면

| 경로 | 설명 |
|------|------|
| `/login` | 테스트 로그인 |
| `/home` | 오늘의 QT · 본문 + 작성 |
| `/qt` | 오늘의 QT 작성 · 완료 |
| `/history` | 나의 QT 월간 캘린더 |
| `/group` | 우리 순 참여 현황 |
| `/ranking` | 전체 순 월간 랭킹 |
| `/me` | 마이페이지 |
| `/admin` | 관리자(Mock) — 일괄 배정 / 순 / 시상 |
